# Trastocker
[![FOSSA Status](https://app.fossa.com/api/projects/git%2Bgithub.com%2Fhuuyafwww%2Ftrastocker.svg?type=shield)](https://app.fossa.com/projects/git%2Bgithub.com%2Fhuuyafwww%2Ftrastocker?ref=badge_shield)


自宅の消耗品を在庫管理するためのシステム。

## Installation

||version|
|---|---|
|Node.js|>= 22.12.0|
|pnpm|>= 9.14.4|

```bash
brew install tbls
pnpm install
pnpm run build:libraries
```
